# Phase 6 progress - public metadata and sharing foundation

Phase 6 has started with independent public-page work. It is not complete. Phases 3-5 retain their documented incomplete/dependent work. The owner-directed deferral of hosted/provider/device integration checks remains in force, and the withdrawn local live-provider testing proposal remains ignored. This increment uses ordinary isolated development checks only; no hosted schema/environment/billing/owner/MFA changes were performed.

## Implemented scope

- Default-off `PHASE_6_ENABLED` controls new public metadata on home, shop, validated category/occasion collections, published product pages and existing public information pages. It is independent of unfinished account/order/admin features. Public helper inputs explicitly exclude private canonical paths, credential-bearing origins and private/external image endpoints.
- Canonicals use the configured clean origin and allow-listed public paths. Normal 24-item, unfiltered numbered pagination preserves a bounded page parameter; search/filter/sort and nonstandard-size variants point to their clean collection hub. Search/message/token/tracking text is never copied into metadata URLs. This is a staging foundation, not a claim that filtered pages are identical or that future production indexing strategy is validated. Unknown products/taxonomy receive generic noindex metadata without reflecting an unknown slug into a canonical.
- Open Graph and large Twitter cards use either a designated published product-media path or a constant brand share card. Login-gated product metadata stays generic and excludes product names/photos. Private pages inherit at most generic brand sharing fields and receive no new canonical or personal metadata. No contact/message/photo/grant/session data is added to social metadata.
- `/share-card/v1` is a versioned, build-generated 1200x630 PNG using Next ImageResponse and constant code-rendered brand typography. It ignores request/query content, makes no auth/database request and sets no cookie in observed preview HTTP checks. Its generated PNG was 43,462 bytes in this build and was visually inspected. The public asset exists even while the metadata flag is off; only enabled metadata advertises it. It is not added to the service-worker cache allow-list.
- Only real, ungated published-catalogue DTOs may produce product-page JSON-LD. Demo and gated products emit none. Ungated live products get breadcrumbs; Product rich-result blocks require a positive approved visible one-decimal average and a positive review count. The scale is explicitly 0-5. Zero/unrated/unapproved/nonfinite aggregates omit the Product block rather than changing actual displayed ratings or emitting an incomplete block. No Offer, final checkout price, stock availability or sales claim is invented. Where a Product block is supported by ratings, its optional starting price is an explicitly provisional PropertyValue, preserving actual zero; absent price stays absent.
- JSON-LD projects selected public fields, excludes private/external image URLs, escapes markup delimiters and Unicode separators through the existing jsonLd serializer, and uses the request CSP nonce. No raw catalogue object is spread into the schema. The scoped lint exception documents this escaping requirement; the general security lint rule stays enabled.

## Preserved boundaries and baseline

Root robots metadata and X-Robots-Tag remain noindex/nofollow, robots.txt still disallows all crawling and the sitemap stays empty because no staging page is indexable. No production-indexing switch was introduced. CSP and private/no-store behavior remain; there is no shared HTML/session cache, public image-optimizer expansion, new ISR policy, offline draft/contact/photo cache, offline submit queue, analytics collector or locale/policy change.

The existing hosted Phase 1 lab baseline remains performance 95 and LCP about 1.8 seconds for its recorded deployment/proxy conditions in phase-1-performance-pass.md. No new Lighthouse score, bundle improvement, production latency or real-user percentile is claimed for this increment. Browser/provider/cache-isolation performance acceptance remains deferred. Fonts, product image optimization and service worker behavior were not changed.
